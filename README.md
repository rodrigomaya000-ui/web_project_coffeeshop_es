# Triple Espresso

## Descripción

Sitio web para la cafetería de la biblioteca Triple Espresso. Una landing page moderna y responsive que presenta los servicios y permite hacer reservas.

## Tecnologías utilizadas

- HTML5
- CSS
- Flexbox
- Metodología BEM

## Cómo ver el proyecto

1. Clona este repositorio
2. Abre el archivo 'index.html' en tu navegador

## Funcionalidades

- Diseño responsive
- Formulario de reservas
- Navegación intuitiva
- Diseño moderno y accesible
